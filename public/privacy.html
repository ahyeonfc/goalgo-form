골고 폼 개인정보처리방침

시행일: 2026년 11월 27일 · 버전 1.1(베타) · 1.1: 구글 드라이브 동기화(이용자가 켤 때만) 추가

골고 폼(이하 "앱")은 축구 개인 훈련 영상을 분석해 코칭을 보여 주는 웹 앱입니다. 앱은 영상과 분석 결과를 운영자에게 보내지 않는 것을 원칙으로 만들어졌습니다. 이용자가 구글 드라이브 동기화를 켜면, 분석 기록이 이용자 본인의 구글 드라이브에만 저장됩니다(4항).

1. 처리하는 정보와 위치

정보어디에 있나왜
키(cm), 주발이용자 기기의 브라우저 저장소(IndexedDB)영상 속 크기 환산, 왼발·오른발 구분

  • 분석은 이용자 기기의 브라우저 안에서만 이루어집니다. 운영자 서버로 영상·관절 좌표·결과를 보내지 않으며, 운영자는 이를 볼 수 없습니다.
  • 회원 가입, 이름, 전화번호를 받지 않습니다. 구글 드라이브 동기화를 켠 경우에만 구글 계정 이메일을 이 기기 안에 기억합니다(다음 로그인을 편하게 하려는 것이며 운영자에게 보내지 않음).
  • 이용 통계·광고 추적 도구를 쓰지 않습니다.

2. 외부로 연결되는 곳

앱을 열거나 분석할 때 아래 주소에서 프로그램과 분석 모델 파일을 내려받습니다. 이때 일반적인 웹 접속처럼 해당 회사가 접속 기록(IP 주소, 브라우저 정보)을 받을 수 있습니다. 영상이나 결과는 보내지 않습니다.

3. 보관과 삭제

  • 기기에 저장된 기록은 이용자가 지울 때까지 보관됩니다. 결과 화면의 "이 기록 지우기"로 하나씩, 브라우저 설정의 "사이트 데이터 삭제"로 모두 지울 수 있습니다.
  • 앱을 지우거나 브라우저 데이터를 지우면 기록이 함께 사라지며, 운영자가 되살릴 수 없습니다.
  • "결과 파일 받기"로 내려받은 파일은 이용자가 직접 관리합니다.

4. 구글 드라이브 동기화(선택)

설정에서 "구글 드라이브 연결"을 누른 이용자만 사용합니다. 켜지 않으면 동작하지 않습니다.

  • 저장 위치: 이용자 본인의 구글 드라이브 "골고폼" 폴더. 운영자 서버를 거치지 않고 이용자 기기에서 구글로 바로 보냅니다. 운영자는 이 파일을 볼 수 없습니다.
  • 저장하는 것: 분석 기록(코칭 결과, 관절·공 좌표 원재료, 장면 사진, 메모)과 키·주발. 훈련 영상은 올리지 않습니다.
  • 권한: drive.file — 골고 폼이 만든 파일만 보고 고칠 수 있으며, 이용자 드라이브의 다른 파일은 볼 수 없습니다.
  • 목적: 다른 기기에서 같은 기록을 보고, 기기를 바꿔도 기록을 지키기 위함입니다. 그 밖의 용도(광고, 판매, 모델 학습 등)로 쓰지 않습니다.
  • 그만두기: 설정의 "연결 끊기"로 권한을 거둘 수 있고, 구글 계정 설정(보안 → 서드 파티 연결)에서도 끊을 수 있습니다. 드라이브의 "골고폼" 폴더를 지우면 저장된 기록이 지워집니다.

골고 폼이 구글 API 에서 받은 정보를 쓰고 다른 곳으로 옮기는 일은 제한적 사용 요건을 포함한 Google API 서비스 사용자 데이터 정책을 따릅니다.

코치와 결과 공유 같은 기능을 더하면, 그 기능을 켤 때 무엇이 어디로 가는지 이 방침을 고치고 앱에서 먼저 알려 드립니다.
