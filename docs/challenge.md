# 골고 폼: 도전 모드

2026-11-27 첫 판. 과제를 골라 하는 법·시범을 보고, 찍어 올리면 단계 통과를 판정하고 일지에 남긴다.
자유 분석(찍은 영상만 넘기면 자동 판별, lesson-build.md 1절)과 함께 둔다.

## 구조 (2026-11-27 사용자와 정함)
- **항목 = 무엇을 잘하게 되나(능력).** 경계를 한 줄 규칙으로 정한다.
- **과제 = 배치 + 하는 방법.** 앞 과제에서 익힌 동작을 가져다 하나씩 더한다(사다리).
- **변형 = 같은 과제에서 바꾸는 조건**(발 부위, 주발/반대발, 방향). 과제를 늘리지 않고 변형으로 둔다.
- **단계 = 숙련도.** 기본 틀: 정확하게 → 빠르게(내 1단계 최고 대비) → 고개 들고 → 오래·양발. 과제에 맞게 바꿀 수 있다.
- 같은 단계를 `pass_need`(2)번 통과하면 다음 단계.
- 단계 숫자는 **골고 폼이 정한 첫 판 규칙**(연구 기준 아님)이라 화면에 그렇게 표시하고, 써 보며 고친다. "빠르게"는 절대 숫자 대신 **내 기록 대비**로 둔다(숫자를 지어내지 않는 원칙).
- 시범 애니메이션은 엔진 시험과 같은 합성 동작(`js/sim.js`)을 그린다. 설명용이며 점수·단계 기준으로 쓰지 않는다.

## 항목 초안 (사용자 확인 중)
| 항목 | 경계 규칙 | 상태 |
|---|---|---|
| ① 공 다루기 | 거의 제자리, 공을 발에 붙여 다룸 | **첫 판 구현**: 토 탭 → 당기고 인사이드 밀기 → 당기고 아웃사이드 밀기 |
| 리프팅 | 공을 떨어뜨리지 않고 차올림 | **첫 판 구현** |
| ② 공 몰기 | 공을 몰고 이동 | 사다리 초안(직선 → 멈추기 → 콘 돌기 → 8자 → 슬라럼 → 속도) |
| ③ 기술(턴·페인트) | 한 동작으로 방향·속도를 갑자기 바꿈 | 초안(당겨 돌기 → 인사이드 컷 → 아웃사이드 컷 → 크루이프 → 시저스·스텝오버 → 조합) |
| ④ 받기 | 오는 공을 받아 다음 동작 준비 | 초안 |
| ⑤ 차기 | 공을 목표로 보냄(패스·슈팅) | 초안 |
| ⑥ 몸 | 공 없이 움직임 | 초안 |

## 공 다루기 사다리 (사용자 정리, 2026-11-27)
1. **토 탭**: 발바닥 앞쪽으로 공 윗부분을 양발 번갈아. 가장 기본.
2. **당기고 인사이드 밀기**: 발바닥으로 몸 쪽으로 당김 → 같은 발 안쪽으로 **앞으로** 살짝 밂 → 반대 발로 같은 동작, 양발 번갈아. 공은 앞뒤로 짧게 왔다 갔다.
3. **당기고 아웃사이드 밀기**: 같은데 발 바깥쪽으로 앞으로.
- 미는 발은 "당긴 발과 같은 발"로 가정했다(사용자 확인 대기). 다르면 `js/sim.js` 시범과 `mastery.js` 반복 세기(당기기 다음 같은 발 밀기)를 고친다.
- 다음 후보: 당기고 디딤발 뒤로(L), 조합.

## 판정 방법 (엔진)
| 과제 | 세는 방법 | 찍는 자리 |
|---|---|---|
| 토 탭 | 발끝이 공에 가장 가까운 순간 + 그 발이 바닥에서 떠 있음(공 위). 공 옆에 선 발은 바닥에 붙어 있어 걸러짐 | 옆 3m, 낮게 |
| 당기고 밀기 | 공 움직임이 바뀐 터치(엔진 터치 찾기) 중 직후 공이 몸 쪽으로 가면 당기기, 멀어지면 밀기. 당기기 다음 0.8초 안에 밀기 = 1번 | 옆 3~4m(앞뒤 움직임이 화면 가로) |
| 리프팅 | 공이 내려오다 다시 올라가는 가장 낮은 점이 바닥보다 위이고 몸 부위(발·무릎·머리)가 가까이 = 닿음. 처음 띄우기는 위로 확 올라가는 것으로. 바닥 높이까지 내려오면 떨어뜨림 | 옆 3~4m, 머리~발·공 꼭대기까지 |
- 인사이드·아웃사이드 구분은 아직 하지 않는다(옆에서 찍으면 좌우가 깊이 방향). 과제를 고른 것으로 믿는다.
- 엔진 숫자는 `criteria/challenge.json` engine 칸(첫 판). 실제 영상으로 맞춘다.

## 파일
- `criteria/challenge.json`: 묶음·과제(하는 법, 잘하는 사람은, 흔한 실수, 찍는 자리, 보여 줄 지표, 단계·규칙), 지표 이름, 엔진 숫자
- `js/engine/challenge.js`: 과제 분석(analyzeTask), 단계 판정(checkLevel, 내 기록 대비 rel 규칙), 진행(progress)
- `js/motions/mastery.js`, `js/motions/juggle.js`: 세기
- `js/sim.js`: 합성 동작(시험·시범 공용), `js/demo.js`: 시범 애니메이션
- `test/challenge.test.mjs`: 시험 9개
