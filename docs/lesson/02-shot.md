# 골고 폼 2: 슈팅 (인스텝 킥 중심, 인사이드 슈팅 포함)

큰 설계: [../lesson-criteria.md](../lesson-criteria.md). 2026-11-27 첫 판.

## 요약
- 슈팅은 연구가 가장 많은 동작이다. **성인 아마추어 값**(Scurr & Hall 2009, 7명; Zago 2014 인사이드, 9명)과 세미프로·엘리트 값이 있다. 표본은 작다.
- 옆에서 찍은 카메라 한 대로 믿을 만한 것: **디딤발 앞뒤 거리, 디딤 무릎 굽힘, 공 속도(120fps), 접근 걸음 수·리듬**.
- 발이 공에 닿는 시간은 약 9ms 다. 30fps(33ms)로는 닿는 순간을 거의 못 찍는다. 그래서 **슈팅은 120fps 슬로모션으로 찍는다.** 30fps면 공 속도·발 속도는 점수에서 뺀다.
- 디딤발 옆 간격, 접근 각도, 골반·몸통 회전은 옆 카메라로는 안 보인다. 뒤 카메라로 따로 찍은 날만 잰다.
- 각도 표기가 연구마다 다르다(굽힘 각도 / 180°=편 상태). 이 문서는 모두 **굽힘 각도**(0° = 완전히 편 상태)로 바꿔 적었다.

## ③ 동작 정의

### 훈련 방식
| 항목 | 내용 |
|---|---|
| 공 | 정지한 공. 차는 자리에 표시 |
| 거리·목표 | 골대가 있으면 페널티 지점(11m)에서 골대. 골대를 좌·우·가운데 × 위·아래 6구역으로 나눠 목표 구역을 미리 말하고 찬다. 골대가 없으면 벽에 같은 크기 표시 |
| 접근 | 공 뒤에서 스스로 고른 각도, 2~4걸음 |
| 횟수 | 주발 6회(구역마다 1회) + 반대발 3회. 첫 1회는 연습 |
| 세기 | 최대 세기(정확도를 유지할 수 있는 만큼) |
| 인사이드 슈팅 | 같은 방식으로 3회 따로 (구석 노리기) |

### 찍는 자리
- **기본: 디딤발 쪽 옆**(오른발잡이는 공의 왼쪽), 공–골대 선에 직각으로 약 5m, 높이 약 1m. 디딤 무릎이 가리지 않고 보이며, 공이 화면 가로로 날아가 속도를 잴 수 있다.
- **120fps 슬로모션 필수**(폴드3·S25 기본 카메라 슬로모션). 화면에 공 뒤 3m(접근)와 공 앞 3m(공 비행 초반)가 들어오게.
- **선택: 공 뒤, 공–골대 선 위 약 4m, 높이 1.5m**. 접근 각도, 디딤발 옆 간격, 반대 팔 벌림, 공 출발 방향이 보인다. 30fps 로 충분.
- 결과(어느 구역에 들어갔는지)는 사람이 화면에서 누르는 것으로 시작한다(옆 카메라로는 골대 구역이 깊이 방향이라 판단이 어렵다).

### 단계
| 단계 | 시작 | 끝 |
|---|---|---|
| 접근 | 첫 걸음 | 디딤발 착지(`plant`) |
| 디딤 | `plant` | `impact` |
| 임팩트 | `impact` 앞뒤 1장면(120fps 기준 약 8ms) | — |
| 마무리 | `impact` | 차는 발 착지 또는 임팩트 뒤 0.5초 |
| 공 비행 | `impact` | 공이 화면을 벗어남 |

## ⑤ 기준과 점수

### 기준

### 점수 (첫 판)
- **속도 축**
  - `sht.ball_speed`(120fps 일 때만): 좋은 범위 [26, ∞) m/s, 허용폭 t = 6(20m/s 이하 0점). 세미프로 평균을 만점 시작점으로 둔다. 인사이드 슈팅은 따로 기록만 한다(기준 없음).
  - `sht.target`: 맞힌 비율을 그대로 점수로.
- **퍼포먼스 축**: `sht.steps` 가 2~5걸음이면 100, 아니면 50(접근이 너무 짧거나 김). `sht.brake`·`sht.last_stride` 는 첫 3회 기준선 대비 개인 비교.
- **자세 축**
  - `sht.plant_ap`: 좋은 범위 [−15, 0]cm(공 뒤 0~15cm), 허용폭 15cm. 높음.
  - `sht.plant_knee_imp`: 좋은 범위 [30°, 50°], 허용폭 15°. 보통(절반 비중).
  - `sht.plant_lat`(뒤 카메라가 있을 때): 좋은 범위 [27, 37]cm, 허용폭 13cm. 보통.
  - `sht.kick_hip` 은 2D 엉덩이 각 정확도가 낮아 점수에서 빼고 "엘리트는 임팩트 때 엉덩이가 덜 굽음"을 숫자와 함께 참고로만 보여 준다.
  - `sht.arm`, `sht.follow`: 있음 100 / 없음 0, 보통.
- 동작 점수 = 세 축 평균. 30fps 영상이면 속도 축은 `sht.target` 만.

### 시험
- 디딤발을 일부러 공 앞 / 많이 뒤 / 바르게 딛은 시도를 찍어 `sht.plant_ap` 와 공 속도·뜬 정도가 같이 움직이는지 본다.
- 공 속도는 120fps 영상의 공 이동을 사람이 직접 찍어 계산한 값과 비교(±1.5m/s 안 목표). 공이 카메라 쪽으로 비스듬히 가면 낮게 나오므로 공–골대 선이 화면과 나란한지 촬영 전에 확인한다.

## ⑥ 피드백 (고칠 말)
| 지표 | 범위 밖일 때 |
|---|---|
| `sht.ball_speed` 낮음 | 공이 약합니다. 무릎만 쓰지 말고, 뒤로 끌 때 엉덩이를 펴고 허벅지를 먼저 보낸 뒤 정강이를 채찍처럼 펴세요. 발목은 발등을 편 채 단단히 고정 |
| `sht.steps` 1걸음 | 접근이 짧습니다. 대각선으로 2~4걸음 들어오세요 |
| `sht.brake` 작음 | 디딤에서 몸이 그대로 흘러갑니다. 마지막 걸음을 조금 길게 딛고 디딤발로 몸을 세우세요 |
| `sht.plant_ap` 앞 | 디딤발이 공보다 앞입니다. 공이 땅에 깔립니다. 공 옆이나 조금 뒤에 딛으세요 |
| `sht.plant_ap` 뒤 | 디딤발이 공에서 많이 뒤입니다. 몸이 젖혀져 공이 뜹니다. 한 걸음 더 들어가 공 뒤 10cm 안에 딛으세요 |
| `sht.plant_lat` 멀음 | 디딤발이 공 옆에서 멉니다. 공 옆 한 뼘 반(약 30cm)에 표시를 두고 딛으세요 |
| `sht.plant_knee_imp` 펴짐 | 디딤 무릎이 펴져 있습니다. 살짝 굽혀 착지해 버티세요 |
| `sht.plant_block` 큼 | 디딤 무릎이 착지 뒤 많이 무너집니다. 디딤발로 버티는 힘을 기르세요(한 발 착지 버티기 연습) |
| `sht.trunk` 뒤로 | 몸이 뒤로 젖혀집니다. 몸을 공 위에 두고 무릎이 공 위를 지나게 하세요 |
| `sht.arm` 없음 | 반대 팔이 몸에 붙어 있습니다. 디딤 때 반대 팔을 옆·뒤로 크게 벌렸다가 임팩트 때 당겨 오세요 |
| `sht.follow` 없음 | 차고 나서 다리를 멈춥니다. 공을 지나 목표 쪽으로 차 내고 그 발로 착지하세요 |
| `sht.head` 일찍 듦 | 고개를 일찍 듭니다. 차는 순간까지 공 맞는 곳을 보세요 |
