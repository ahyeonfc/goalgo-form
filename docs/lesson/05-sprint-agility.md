# 골고 폼 5: 달리기·민첩성 (공 없이)

큰 설계: [../lesson-criteria.md](../lesson-criteria.md). 2026-11-27 첫 판.

## 요약
- 기준값이 가장 많은 동작이다. 성인 아마추어·대학·프로 값이 모두 있다.
- **출발 방식에 따라 같은 10m도 0.3~0.4초 차이 난다.** 그래서 출발 방식에 흔들리지 않는 **10~20m 구간 속도**와 **505 시간**(선을 지나는 순간으로 잼)을 점수의 중심으로 둔다. 0~10m·0~20m 시간은 같은 방식으로 잰 내 기록끼리만 비교한다.
- 옆에서 찍은 몸통 각도는 연구도 2D로 쟀고 재현성이 높다. 출발 직후(앞으로 크게 숙임)와 최고 속도(거의 선 자세)처럼 차이가 큰 구분에 쓴다.
- 무릎이 안쪽으로 무너지는 정도(FPPA)는 검증된 부상 기준값이 없다. **위험 판정은 하지 않고** "많이 무너짐(40° 넘음) → 다시 보기 권장" 표시만 한다.
- 시간을 재려면 120fps 이상으로 찍는다(30fps 한 장 = 0.033초).

## ③ 동작 정의

### 과제
| 과제 | 배치 | 횟수 |
|---|---|---|
| **S1. 20m 스프린트** | 출발선, 10m 선, 20m 선에 콘을 양옆 2개씩(선 표시). 출발선 30cm 뒤 서서 출발(두 발 앞뒤, 몸 흔들지 않기) | 3회, 2분 쉬고. 가장 빠른 기록 |
| **S2. 505 방향 전환** | 출발선에서 10m 뒤 시작 → 출발선(계측선)을 지나 5m 앞 돌아오는 선에서 한 발로 180° 돌아 계측선으로 돌아옴. 시간 = 계측선을 처음 지날 때 ~ 다시 지날 때 | 왼발·오른발 디딤 각 2회, 좋은 기록 |
| **S3. 90° 컷 (선택, 무릎 보기)** | 5m 달려 콘에서 90° 옆으로 꺾어 3m | 좌우 각 3회 |

### 찍는 자리
- **S1: 10m 선 옆, 달리는 선에 직각으로 약 12m 떨어져, 높이 약 1m.** 0~20m 가 다 들어오게(폴드3·S25 초광각). 출발선·10m·20m 콘이 화면에 보여야 한다. **120fps** 이상(240fps 면 접지 시간도 잼).
- **S2: 계측선과 돌아오는 선 가운데 옆, 직각으로 약 8m, 높이 1m, 120fps.** 돌 때 몸이 화면과 나란한 면에서 움직여야 마지막 두 걸음이 보인다.
- **S3: 꺾는 콘 정면, 약 6m, 높이 1m(무릎 높이 근처), 60fps 이상.** 무릎이 발끝 안쪽으로 들어가는지 보이는 각도.
- 초광각 가장자리는 휘어 있으므로 시간은 콘(선)을 지나는 순간으로만 재고, 거리 환산은 콘 위치로 구간마다 따로 한다.

### 단계
| 과제 | 단계 |
|---|---|
| S1 | 출발(첫 움직임 ~ 첫 3걸음) → 가속(~10m) → 최고 속도 구간(10~20m) |
| S2 | 진입(계측선 ~ 마지막 두 걸음 전) → 제동(마지막에서 두 번째 걸음 + 마지막 걸음) → 회전 → 재가속(~계측선) |
| S3 | 진입 → 꺾는 디딤(무릎 각 재는 순간) → 나가기 |

선을 지나는 순간 = 엉덩이 중심이 그 선(콘 두 개를 잇는 선)을 넘는 장면.

### 점수 (첫 판)
- **속도 축**
  - `spr.v1020`: 좋은 범위 [7.8, ∞) m/s, 허용폭 1.3(6.5m/s 이하 0점). 프로·대학 출전 선수 수준을 만점 시작점으로.
  - `cod.t505`(잘 도는 쪽): 좋은 범위 (0, 2.37]초, 허용폭 0.4(2.77초 이상 0점). 반대쪽은 (0, 2.45], 허용폭 0.4.
  - `spr.t10`, `spr.t20` 은 숫자와 추이만(출발 방식이 달라 연구값과 직접 비교 안 함). 화면에 "게이트 측정 기준표보다 0.3초 안팎 느리게 나옴"을 표시한다.
  - `cod.side_gap`: 4% 이하 100, 넘으면 1%p 마다 −10.
- **퍼포먼스 축**: 걸음 빈도·보폭·접지·마지막에서 두 번째 걸음은 프로 값을 그림에 참고선으로만 표시하고 개인 비교(점수 아님). 점수가 비면 퍼포먼스 축은 빼고 표시한다.
- **자세 축**
  - `spr.trunk_start`: 좋은 범위 [35°, 50°](수직 기준 숙임), 허용폭 15°. 높음.
  - `spr.trunk_top`: 좋은 범위 [8°, 16°], 허용폭 10°. 높음.
  - `cod.fppa`: 점수에 넣지 않는다. 40° 넘으면 "무릎이 많이 안쪽으로 들어갑니다, 다시 보기 권장" 표시만.
- 동작 점수 = 속도·자세 두 축 평균(퍼포먼스 기준이 생기면 세 축).

### 시험
- 같은 사람 3회의 `spr.v1020` 차이가 0.2m/s 안인지(재현성).
- 손 스톱워치·다른 폰으로 같은 달리기를 120fps 로 찍어 선 지나는 장면을 사람이 찍은 시간과 비교(±0.02초 안 목표).
- 몸통 각도는 사람이 영상 위에서 직접 그은 선의 각도와 비교(±4° 안 목표, 연구의 최소 감지 변화 2.2~2.7°).
